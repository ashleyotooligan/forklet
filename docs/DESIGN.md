# An experiment folio, not another dashboard

## Visual idea

Forklet begins as one folded form and becomes two information paths. The mascot has a central crease, not a robot visor or an animal-brain silhouette. Its cobalt and coral inner folds provide the same two-branch language used in plots and annotations.

The original portrait and paired artwork use completely plain warm-white backgrounds. There is no laboratory scene, console, floating coin, game environment or decorative screen behind the character.

## Palette

| Role | Value |
|---|---|
| Paper | `#f6f4ef` |
| Ink | `#28303e` |
| A / blue | `#5576bd` |
| B / coral | `#d58a68` |
| Probability divergence | `#917ba7` |
| Night study | `#222b3b` |

Blue means original evidence; coral means the treated branch. Never use green/red alone as “profitable/unprofitable” because the primary comparison is information, not a trading recommendation.

## Twelve compositions

The opening is a title spread. The checkpoint is a passport. Lineage is an open branching diagram. Evidence is a pair of signal strips. Actions become a three-lane film. Hidden state becomes radial sketches. Divergence gets a large scientific plot. The first disagreement gets a full-page color split. Resources get a ledger. Replay gets a tilted archive sheet. Batch results get a sparse dot study. The closing portrait is deliberately plain.

Shared typography and quiet footers connect the folio without forcing every subject into identical cards. The browser control strip sits outside the exported Canvas, so exports remain standalone figures rather than repeated application chrome.

## Typography and readability

The prepared native figures use DejaVu Serif for display, DejaVu Sans for prose and DejaVu Sans Mono for data labels. Browser rendering can use local fallbacks. Text is not drawn into the character artwork. Titles, annotations, figures and exact data labels are code-rendered for consistency and editability.

Canvas is accompanied by DOM captions, status text, labeled controls and keyboard plate navigation. These improve access but are not equivalent to a complete accessible data-table alternative for every chart; see [testing](TESTING.md).
