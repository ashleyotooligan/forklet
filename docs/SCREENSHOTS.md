# Experiment-plate atlas

The repository includes twelve 1440 × 1080 PNG figures and one 1600 × 800 social cover. The twelve figures are generated by the same Canvas drawing functions used in the local interface, with the default engine run and fixed batch study. They are not browser captures. Font rasterization can differ in browsers.

## Recreate them

See [reproducibility](REPRODUCIBILITY.md) for the optional native renderer and font setup. Then run `npm run screenshots`. All twelve files are produced from source, not manually edited numbers. The cover is also code-composed, with original character artwork.

## Share individual images

Use the PNG files directly. Keep surrounding text honest: the model is synthetic; a paper SOL value is not a live wallet balance. The state sketches are computational units, not biological neuron recordings. Do not call the short state identifier a cryptographic or quantum proof.

## Image paths on GitHub

Paths are relative and case-sensitive. `assets/` belongs beside the root `README.md`. Clicking [this image](../assets/screenshots/08-diff.png) should open it directly after a complete upload. A 404 means the file or its folder was not uploaded at the expected path.
