# Roadmap

## Included in 0.1.0

- Complete serializable recurrent state and deep fork.
- Four declared interventions with an unchanged negative control.
- Shared external world and common action draws.
- Per-step inputs, activations, distributions, actions and paper execution.
- Twelve-seed reference study and replay examples.
- Twelve distinct experiment plates, original character art and a standalone offline edition.
- Engine, replay, data and DOM-wiring tests; package and integrity checks.

## Next experimental work

| Direction | Acceptance criterion |
|---|---|
| Memory ablation | Saved baseline; explicit overwritten fields; negative control still identical |
| Intervention sweep | All durations, seeds and failed hypotheses reported |
| Independent replicates | Clear sampling plan; uncertainty definitions; no seed selection by outcome |
| Alternate controller | Versioned state contract; no false hidden-state cloning claim |
| Fixture import | Timestamp cutoffs, provenance and missing-data rules |
| Browser validation | Real engine screenshots, keyboard checks and accessibility review |

## Optional evidence infrastructure

A separate content-digested receipt bundle could later be anchored on Solana. This requires a serialization specification, signing model, deployment, independent verification and user-visible transaction status. It is not needed to run the current experiment and is not implemented.

## Non-goals

No token launch requirement, self-custody wallet handling, automatic trading, guaranteed return, proprietary-model reconstruction, quantum marketing claim, or AGI declaration. Keep the experimental question sharper than the narrative around it.
